# VIAL 360 — Gestión de Asistencia Vial

Página de entrada de **VIAL 360**: https://vial-360.github.io/

Abre la aplicación web (Google Apps Script) a pantalla completa y permite instalarla en el celular
("Agregar a pantalla de inicio") con el ícono de VIAL 360.

- `index.html` — pantalla de carga y aplicación. El enlace de la aplicación está en la constante `APP_URL`.
- `manifest.webmanifest`, `sw.js` — instalación como aplicación en el celular.
- Íconos: `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png`, `favicon.ico`; vista previa al compartir: `og-vial360.jpg`.

Este repositorio no contiene claves ni datos. El código de la aplicación está en el repositorio privado `vial-360`.
